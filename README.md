# Hydeense

Hyperland desktop environment setup

## О проекте

> Что это?

Cборка рабочего окруженя на базе чистого archlinux.

> Зачем?

Я хочу полностью подточенную под себя систему, которую я понимаю на 100% и могу кастомизировать под себя как мне угодно.

> Что из себя представляет сборка?

В основном это набор конфигов и скриптов для установки и настройки программ необходимых мне на моей рабочей машине. Есть некоторые особенности сборки которых я буду придерживаться:

- Идемпотентность. Первоначальный запуск и последующие обновления не будут ломать текущую систему.
- Обновляемость. Новые изменения можно применить на работующую сборку предыдущих версий.
- Откатываемость. Можно поставить обновление и в случае ошибок отктиться к предыдущей версии
- Персистентность. Существующие конфиги не изменяются неявно при обновлениях
- Возобновляемость. Одна команда - одинаковый результат
- Модульность. Можно установить базовый функционал без оконного меннеджера и GUI программ

> Какие инструменты лежат в основе сборки?

Вот некоторые приложения и инструменты которыми я пользуюсь повседневно

- nvim
- tmux
- hyperland
- firefox
- alacritty
